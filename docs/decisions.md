# Architecture Decision Records (ADR)

## ADR-001: GD/빅뱅 20주년 투어 앵커 기반 점진적 확장 전략
- **상태**: 승인됨 (Accepted)
- **일자**: 2026-08-27
- **결정**: 초기 트래픽 확보를 위해 GD/빅뱅 20주년 18개 도시 투어를 앵커로 전면에 배치하되, 데이터 스키마는 처음부터 `artistId`, `tourId` 기반 범용 다중 아티스트 구조로 설계한다.
- **이유**:
  1. 단일 팬덤(솔로+그룹) 및 글로벌 18개 도시 순회로 다국어 트래픽 즉시 확보 가능.
  2. 추후 BTS, 블랙핑크 등으로 확장 시 스키마 마이그레이션 비용 제로화.

## ADR-002: Express/WebSocket 상시 서버 배제 및 Firestore 네이티브 실시간 리스너 채택
- **상태**: 승인됨 (Accepted)
- **일자**: 2026-08-27
- **결정**: AI Studio 초기 프로토타입의 Express + 커스텀 WebSocket(`/ws`) 상시 서버를 전면 제거하고, 클라이언트 SDK 기반의 `onSnapshot()` Firestore 네이티브 리스너 아키텍처로 전환한다.
- **이유**:
  1. **인프라 운영비 제로**: 24시간 켜두어야 하는 Cloud Run/컨테이너 서버 비용 없이 순수 서버리스로 구동.
  2. **무한 자동 스케일링**: 동시 접속자 수가 급증해도 Google Cloud Firestore가 커넥션을 자동 관리.
  3. **데이터 정합성 보장**: 서버 메모리와 DB 간의 상태 불일치 리스크를 없애고 Firestore를 단일 진실 공급원(SSOT)으로 확립.

## ADR-003: 저작권 안심 팩트 요약(Fact-only) 및 8-gram 표절 방지 필터 도입
- **상태**: 승인됨 (Accepted)
- **일자**: 2026-08-28
- **결정**: 언론사 기사 원문을 직접 인용하지 않고, 객관적 사실(날짜, 장소, 티켓 오픈일, 가격)만 Gemini AI로 추출하며 8단어 n-gram 연속 일치 시 표절로 판정해 차단한다.
- **이유**:
  1. **저작권/초상권 리스크 원천 차단**: 사실 정보(Fact)는 저작권 보호 대상이 아니므로 자유롭고 안전하게 재가공 가능.
  2. **출처 신뢰성**: 소속사 공식 공지, 공인 예매처(NOL, 인터파크 등) 도메인 화이트리스트 검증을 통과한 정보만 공개.
  3. **다국어 팬덤 최적화**: 단순 직역이 아닌 현지 언어 문화(일본어 공손체 등)에 맞는 자체 문장으로 재구성.

## ADR-004: 관리자 인증 PIN 제거 및 Firebase Authentication (Custom Claims) 전환
- **상태**: 승인됨 (Accepted)
- **일자**: 2026-08-29
- **결정**: 하드코딩된 4자리 PIN(2026) 방식을 완전히 폐기하고, Firebase Authentication (이메일/비밀번호 + Google SSO) 및 Custom Claim(`admin: true`) 기반의 RBAC(역할 기반 접근 제어)로 전면 전환한다.
- **이유**:
  1. **브루트포스 공격 차단**: 4자리 PIN의 사전 공격/무차별 대입 공격 취약성을 원천 제거.
  2. **클라이언트 조작 불가**: `request.auth.token.admin == true`를 Firestore Security Rules 레벨에서 강제하여 클라이언트 변조를 방지.
  3. **감사 추적성(Audit Trail)**: 어떤 관리자 계정이 뉴스나 언어 콘텐츠를 승인/반려했는지 계정별 추적 가능.

## ADR-006: SEO 렌더링 전략 및 Discord 웹훅 통합 (X 자동화 보류)
- **상태**: 승인됨 (Accepted)
- **일자**: 2026-08-29
- **결정 사항**:
  1. **SEO 전략**: 정적 `sitemap.xml`, `robots.txt`, Schema.org `MusicEvent`/`MusicGroup` JSON-LD 구조화 데이터 및 Open Graph 리치 카드 태그를 적용하여 검색엔진 색인 및 소셜 공유 최적화.
  2. **멀티채널 디스패처**: 단일 트랜잭션 관문(`notifiedStatuses`)을 통해 이메일과 Discord 웹훅으로 독립적 팬아웃(Fan-out) 구현 (장애 격리).
  3. **X(트위터) 자동화 보류**: X API 유료화(월 $100~ 최소 비용)로 인해 이번 릴리즈에서 제외하고, 무료 채널인 Discord 웹훅을 우선 도입. (향후 예산 승인 시 1줄로 추가 가능한 디스패처 구조 확보).

## ADR-007: 만 14세 가입 제한 게이트 및 개인정보 최소 수집 (Privacy-by-Design)
- **상태**: 승인됨 (Accepted)
- **일자**: 2026-08-30
- **배경**:
  - 한국 정보통신망법(만 14세 미만 법정대리인 동의 필요) 및 미국 COPPA(만 13세 미만 보호) 준수를 위해 글로벌 공통 "만 14세 미만 가입 제한" 정책 적용.
- **결정 사항**:
  1. **가입 플로우**: 이메일 가입 및 최초 Google 소셜 로그인 시 출생년월 1회 검증 강제. 만 14세 미만은 가입 차단.
  2. **데이터 최소화**: 출생년월은 나이 계산 후 즉시 폐기하며, Firestore에는 `ageVerified: true`와 `ageVerifiedAt` 플래그만 보관 (법적 책임 및 침해 위험 최소화).
  3. **기존 사용자 마이그레이션**: 기존 가입자는 이전 정책 통과자로 간주하여 `ageVerified: true`로 일괄 자동 인정(Grandfathering).
